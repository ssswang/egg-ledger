# 🍳 鸡蛋账本

每天领了多少鸡蛋、什么时候最容易出好结果、自己的最高纪录是多少——不必再靠记忆。

鸡蛋账本是一款轻量的个人领取记录工具。打开就能记下一次结果，随后把零散的“手气”变成一眼看得懂的统计和历史。

*一代人有一代人的鸡蛋要领。*

## 它有什么用

- **快速记一笔**：输入本次领取数量，时间自动记录；也支持小数。
- **看清今天的状态**：随时查看今日和过去 24 小时的成功、尝试与领取数量。
- **保留每一次结果**：成功、攒攒手气都能清楚区分。
- **找到自己的纪录**：历史单次最多会被单独标出，方便回顾最好的手气。
- **成功视图**：把某一天成功领取的结果排成领奖小卡，直观看到当天收获。
- **长期回顾**：更多统计中可以查看本月表现与最近 7 天的变化趋势。
- **方便留存**：可导出 CSV，也能把之前导出的 CSV 导入并合并新记录。

## 适合谁

适合想认真记录每日领取、想比较不同日期手气、或只是希望把“今天领了多少”记清楚的人。

例如，你可以用它记录 B 站的电池红包、抖音的钻石红包，或任何需要每天领取、结果会随手气变化的小奖励。

## 简单、私密、为自己而记

鸡蛋账本不需要复杂设置。选择你习惯的时区，随手记录结果，剩下的交给统计和历史。

愿每一次打开，都是一次好运的见证。🥚
