# 鸡蛋账本

这是一个零依赖、可离线运行的渐进式网页应用（PWA）。网页版记录保存在当前设备的浏览器本地存储中；Android 原生工程会改用 SQLite 数据库。数据不会上传到服务器。

## 使用方式

在此文件夹中启动任意本地静态网页服务，然后用浏览器打开。Chrome 或 Edge 的地址栏会提供“安装”按钮；Android Chrome 可从浏览器菜单选择“安装应用”或“添加到主屏幕”。

首次启动默认使用北京时间（Asia/Shanghai）；可在右上角设置中更改。填写 `-1` 代表消费 1 个鸡蛋，填写 `0` 代表攒攒手气，填写正数（可带小数，例如 `1.3`）代表成功，并自动写入当下时间戳。

## 统计口径

- 今天：所选时区的自然日。
- 24 小时：从此刻倒推 24 小时。
- 今日鸡蛋、平均：只统计领取数量大于 0 的成功记录；平均值 = 今日鸡蛋 / 今日成功次数。
- CSV：导出所有记录和当前显示时区下的格式化时间。
- 数据备份：可导出 CSV 文件，便于长期保存和用表格软件查看；导入 CSV 时会合并新记录，不会清空现有记录。
